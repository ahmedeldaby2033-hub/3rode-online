# المزامنة التلقائية — زر «مزامنة الآن» يحدّث كل شيء فوراً

## الفكرة

زر «مزامنة الآن» في لوحة التحكم كان يسجّل طلباً فقط في سجل المزامنة،
ولا يحدّث الموقع إلا مع تشغيل المزامنة الساعية (التي لم تُفعَّل بعد).
الآن الزر يرسل أحدث بيانات الشيت مباشرة إلى **خدمة مزامنة صغيرة**
(`scripts/sync-webhook/`) تعمل على الخادم، فتنفذ كامل الخطوات فوراً:

1. تستقبل بيانات الشيت (التصدير من Apps Script) وتكتبها في `data/raw/`.
2. تشغّل `scripts/sync.py` مراراً حتى تنتهي صور الموديلات الجديدة.
3. تحفظ التغييرات وترفعها إلى GitHub (بمفتاح نشر Deploy Key).
4. تطلب إعادة النشر من Coolify عبر رابط النشر (Deploy Webhook).
5. تعرض اللوحة تقدّم العملية لحظة بلحظة ثم النتيجة.

## الإعداد (مرة واحدة)

### 1) مفتاح النشر Deploy Key — لرفع التغييرات إلى GitHub

على الخادم (طرفية Coolify)، نفّذ:

```bash
ssh-keygen -t ed25519 -f /opt/3rode-online/deploy-key -N "" -C "3rde-sync"
cat /opt/3rode-online/deploy-key.pub
```

انسخ المفتاح العام الظاهر، ثم في GitHub:
**المستودع 3rode-online ← Settings ← Deploy keys ← Add deploy key**
— الصق المفتاح العام، وفعّل خيار **Allow write access**، ثم احفظ.

> المفتاح الخاص يبقى على الخادم ولا يُرسل في المحادثة أبداً.

### 2) رابط نشر Coolify — لإعادة نشر الموقع تلقائياً بعد كل رفع

في لوحة Coolify، افتح تطبيق **3rode-online** ← تبويب **Webhooks** ←
انسخ رابط **Deploy Webhook** (يبدأ بـ `https://cp.3rodd.online/api/v1/...`).

### 3) إنشاء تطبيق خدمة المزامنة في Coolify

في لوحة Coolify ← **New Resource ← Application** من نفس المستودع
`ahmedeldaby2033-hub/3rode-online` والفرع `main`، ثم:

- **Build Pack:** Dockerfile
- **Dockerfile Location:** `scripts/sync-webhook/Dockerfile`
- **Domain:** `sync.3rde.online` (أو أي نطاق تفضله)
- **متغيرات البيئة (Environment Variables):**

| المتغير | القيمة |
|---|---|
| `SYNC_TOKEN` | رمز قوي من اختيارك (هو نفسه الذي تلصقه في لوحة التحكم) |
| `DEPLOY_KEY` | محتوى المفتاح الخاص كاملاً (`cat /opt/3rode-online/deploy-key`) |
| `COOLIFY_DEPLOY_WEBHOOK` | رابط النشر من الخطوة 2 |
| `REPO_URL` | `git@github.com:ahmedeldaby2033-hub/3rode-online.git` |

ثم **Deploy**. تأكد أن `https://sync.3rde.online/health` يرد `{"ok": true}`.

### 4) ربط لوحة التحكم بالخدمة

في لوحة التحكم ← تبويب **«الإعداد والربط»** ← قسم **«خدمة المزامنة الفورية»**:
الصق رابط الخدمة (`https://sync.3rde.online`) والرمز `SYNC_TOKEN` نفسه،
ثم اضغط **«حفظ إعدادات المزامنة»**. يُحفظان في متصفحك فقط (localStorage).

## الاستخدام

من تبويب **«نظرة عامة»** اضغط **«مزامنة الآن (طلب تحديث)»** — ستظهر حالة
العملية أسفل الزر: جلب بيانات الشيت، تشغيل المزامنة، الرفع إلى GitHub،
إعادة النشر. عند اكتمالها تظهر النتيجة (عدد الموديلات والعروض والصور).

- إن لم تكن هناك تغييرات، تُظهر النتيجة «لا تغييرات جديدة» ولا يُعاد النشر.
- الصور التي تفشل روابطها في الشيت تُستبدل بصورة بديلة، وتظهر في تحذير البناء.
- طلبات المزامنة تُسجَّل أيضاً في تبويب «سجل المزامنة» بالشيت كما كان سابقاً.

## ملاحظات أمنية

- الخدمة تقبل الطلبات فقط مع الرمز الصحيح (`SYNC_TOKEN`) — لا تنشره.
- المفتاح الخاص (`DEPLOY_KEY`) يمنح الكتابة على هذا المستودع فقط.
- الخدمة لا تكتب في الشيت أبداً — الشيت مصدر للقراءة فقط.
